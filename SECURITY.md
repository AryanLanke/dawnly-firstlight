# Security policy

## Reporting a problem

If you find a security issue in this website or the Dawnly app, email redischarmender@gmail.com with the details. Please don't open a public issue for it. You'll get a reply as soon as I can manage.

## Getting the real APK

Only download Dawnly from the official site: https://dawnlyapp.pages.dev

Dawnly is not on the Play Store, so any copy from another site, chat, or file-sharing link isn't from me. Official releases are signed with the same certificate every time. If Android refuses to update an installed Dawnly with a new APK, the file was signed with a different key and you shouldn't install it.

## What this site stores

The website keeps one number: the total of confirmed downloads. It stores no personal data. See the [privacy policy](https://dawnlyapp.pages.dev/privacy).
